점주 이메일 초대와 포스기 PC 즐겨찾기

2026년 11월 19일 · 웹앱 v0.391 화면 기준

1. 본사에서 점주 이메일 초대

  1. 근태관리 웹앱에 본사 관리자 계정으로 로그인합니다.
  2. 본사 대시보드에서 계정 관리를 열고, 점주를 지정할 지점을 검색·선택합니다.
  3. 관리자 초대 탭에서 역할을 대표 관리자로 선택합니다. (보조 관리자는 별도 역할입니다.)
  4. 실제 점주가 사용하는 이메일 주소를 정확하게 입력합니다.
  5. 대표 초대·개통 승인 메일 발송 버튼을 눌러 결과를 확인합니다. 화면 버전에 따라 점주 개통 안내 메일 발송으로 표시될 수 있습니다.
  6. 초대 대상이 초대 대기중으로 표시되는지 확인하고, 수신자에게 받은편지함·스팸함을 확인하도록 안내합니다.
  7. 점주는 받은 메일의 공식 링크로 들어가 개인 비밀번호를 설정하고 최초 로그인합니다.
  8. 본사는 관리자 현황에서 해당 지점 대표 지정 여부를 확인합니다. 실제 지점 계정으로 로그인한 뒤 자기 지점만 표시되는지 점검합니다.

주의: 초대 메일 발송 접수는 수신 완료가 아닙니다. 현재 운영 SMTP와 실제 수신 검증은 별도 확인이 필요합니다. 이메일이 도착하지 않거나 링크가 만료되면 무작정 여러 번 초대하지 말고 오류·초대 상태를 확인한 뒤 재발송합니다. 테스트 목적의 다른 지점 직원·급여 데이터는 변경하지 않습니다.

2. 포스기 PC에 근태 사이트 즐겨찾기

먼저 해당 매장의 지점 전용 주소를 열어 상단에 올바른 지점명이 보이는지 확인하세요. 다른 매장 URL을 저장하지 않도록 주의합니다.

지점별 주소 형식:

https://koith.github.io/attendance-proto/index.html?mode=store&store=지점ID#pos

Google Chrome (권장)

  1. 포스기 PC에서 Chrome을 열고 매장 전용 근태 URL로 접속합니다.
  2. 주소창의 별표(☆) 또는 Ctrl + D로 즐겨찾기를 추가합니다.
  3. 이름을 백억커피 근태관리로 정하고 북마크바에 저장합니다.
  4. 필요하면 Ctrl + Shift + B로 북마크바를 표시합니다.
  5. 브라우저를 닫았다가 다시 열고, 즐겨찾기를 눌러 올바른 지점명과 출퇴근 화면이 표시되는지 확인합니다.

Microsoft Edge (권장 대안)

매장 전용 URL 접속 → 주소창 별표 또는 Ctrl + D → 즐겨찾기 추가. 저장 후 브라우저를 다시 열어 점검합니다.

Internet Explorer (기존 포스기 환경)

Internet Explorer 11은 공식 지원이 종료된 오래된 브라우저입니다. 즐겨찾기 기능이 존재하더라도 현재 근태 웹앱의 정상 실행을 보장하지 않으므로 사용을 권장하지 않습니다. 가능하면 해당 포스기에 Chrome 또는 최신 Edge를 설치·사용합니다. Edge의 IE 호환 모드도 현대 웹앱을 위해 사용할 필요가 없습니다.

실제 포스기 확인 사항: 포스기 PC의 Windows 버전, 브라우저 설치 여부, 점주/관리자 설치 권한, POS 전용 잠금 모드에 따라 실제 즐겨찾기 등록이 제한될 수 있습니다. 현재 검증된 것은 웹앱의 PC Chrome 접속이며, 모든 매장의 실물 포스기에서 직접 실행한 것은 아닙니다. 출퇴근 테스트는 운영 직원 기록을 임의 생성하지 않는 방식으로 진행합니다.

이 페이지에는 비밀번호와 실제 점주 이메일 주소가 포함되지 않습니다.
