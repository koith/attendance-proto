# NOV14-INS-01 — 건강보험 EDI 대량 대상자 증빙 첨부 기술조사 (2026-11-15)

**범위와 판정:** 2026-11-14 회의의 기존 확정 원장 `NOV14-INS-01` **조사 전용**. 실제 사용자 약 3,000명, 한 회차 30~50건이라는 숫자는 **회의에서 제시된 가정**이며 공단의 일반적 파일첨부 한도로 검증되지 않았다. 인증서 로그인/인증 우회/실제 파일 업로드/외부 신고 제출을 개발하거나 실행하지 않는다. 이 조사에서 달성 가능한 결과는 공적 문서 기반 경로 판별, synthetic row-file 매핑·재시도 설계, 구현 선택의 근거이다. **실제 첨부 자동화 완료가 아니다.**

## 3. 3,000명 매칭 및 재시도 사양 (합성 fixture 구현)

`scripts/research/edi_attachment_match.mjs`는 **외부 HTTP·실파일 내용·인증서를 다루지 않는 순수 계획기**다. `qa/nov14_ins01_edi_matching.test.mjs`로 격리 검증한다.

- 엑셀에서 추출한 **행별 고유 식별자**(가상 `rowKey`)를 서식의 고유 행 ID와 연결해야 한다. 동일 이름/행 위치만으로 매칭하거나 주민번호를 로그·GitHub에 남기지 않는다. 실제 화면에서 고유 행 ID를 제공하지 않으면 직원 본인확인을 포함한 업무별 명시적 승인 매핑이 선행되어야 한다.
- 파일 manifest의 `rowKey / 파일명 / 길이 / SHA-256`과 대상자 행의 `rowKey / 순번`을 **정확히 1:1** 대조한다. 누락, 복수 매핑, 중복 파일명, 경로 탈출, 중복 행, 파일 해시 오류는 전체 배치를 중단한다. 1인 복수 파일이 필요한 서식은 이 합성 모델로 처리 불가, 새 첨부 계약·테스트 필요.
- `batchSize=40`의 3,000건은 **75배치**. 30명 단위=100배치, 50명 단위=60배치. 이는 사용자 가정에 따른 산술일 뿐 **공단 측 실행 제한이 아니다**.
- 배치 상태는 `QUEUED → LOCAL_MATCHED → UI_OPENED → FILE_SELECTED → UI_VERIFIED → DONE`로 관리한다. `DONE`은 인증된 사용자 화면에서 해당 대상자와 파일명/첨부 결과가 실제로 재확인된 경우에만 허용. 클릭 또는 로컬 파일 선택 자체를 성공으로 인정하지 않는다.
- 중단/재개 checkpoint: `{formId,digest,confirmedKeys}`. 원본 manifest의 정렬된 SHA-256 요약이 달라지면 재개 거부, 확인한 행만 건너뛴다. 더 작은 배치 크기로 재시도해도 UI 재조회 증거가 없으면 `confirmedKeys`에 추가하지 않는다.
- 오류: 유효기간 만료/세션 로그아웃/폼 재정렬/중복 첨부/파일 사이즈/DOM 변경/업로드 지연/네트워크 단절 중 하나면 해당 대상 `NEEDS_REVIEW`, 증빙 미확인 행은 서버 성공으로 간주하지 않는다. 개인별 실제 증빙 문서와 파일명은 별도 접근 제어 저장소에서 관리한다.

## 4. 비용·실행 리스크 / 결정 조건

- 개발비는 전용 업무 서식 및 인증 후 테스트 환경을 볼 수 있어야 추정 가능. **실제 정량 비용·처리 속도는 UNVERIFIED**. 3,000건에 2초/건이면 100분, 10초/건이면 500분(브라우저 수행 자체의 단순 산술)이고, 페이지 로드·첨부 검증·재시도·휴먼 검토 시간을 포함하지 않는다.
- 1건이라도 **타 대상자에게 서류가 오첨부**되면 개인정보 유출이 발생할 수 있다. 파일명·신고번호·개인식별정보를 공개 PR/Actions 로그에 남기지 않는다.
- 인증 이후에도 서비스 제공자의 사용정책과 안전한 DOM/파일 업로드 허용 범위를 확인해야 한다. 숨겨진 인터페이스/캡차·인증서 우회·대량 무단 신고 자동화는 제외.
- **착수 GO:** 정확한 업무 서식/샘플 익명화 행 구조/제공하는 고유 키/대상자별 실제 파일 유형·한도/화면 readback 가능/허용된 자동화 방식이 확정되고, 합성 30~50건의 오류/중단재개가 통과한 경우. 실서류 제출 권한은 별도 승인.
- **착수 NO_GO:** 행 고유키를 얻을 수 없거나 서류별 일치성을 확인할 UI가 없고, 공단 약관·서식 정책이 자동화를 금지하면 클릭 자동화 보류. 이때에도 로컬 자료 대조·체크리스트 도구는 개발 가능.

## 5. 범위 종료 및 후속 작업

이 조사의 **종료조건**은 공식자료 근거, 세 경로 비교, 합성 3,000명 일대일 매칭·60~100배치·누락/중복/변조/재실행 테스트, 실패/감사/권한·비용 리스크 및 GO/NO_GO 판단을 제공하는 것이다. 실제 인원·계정·엑셀·증빙서류는 입수하거나 업로드하지 않았다. **조사 완료 ≠ EDI 자동첨부 실제 구현 완료**. 정확한 서식의 비인증 공개 도움말은 확인했으나, 로그인 후 실제 UI·조항은 원본으로 재확인해야 한다.
