# Attendance / Payroll Domain Rules

## 범위
출퇴근, 실제근무, 근무표, 정정, 대타, 직원, 계약, 급여.

## 고정 원칙
- 원본 attendance event를 임의 수정하지 않고 확정된 correction 모델을 존중한다.
- 타각 상태 판정과 동시성 방어를 약화시키지 않는다.
- 자정 넘김, 분할근무, 미완결/고아 이벤트를 정상 단일세션처럼 취급하지 않는다.
- 근태 수정 UX는 근무현황을 기준으로 유지하며 직원 카드 직접 편집 진입을 만들지 않는다.
- 급여 계산 변경은 기존 근태 데이터와 계약/급여 설정의 권위(authority)를 확인한다.
- 법률·세무 규칙은 사용자/회계 검증 없이 코드 정책으로 확정하지 않는다.

## 증명
관련 기존 QA를 먼저 검색해 재사용한다. 계산 변경은 Golden/replay 자산이 있으면 반드시 함께 실행한다.
