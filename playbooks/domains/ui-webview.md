# UI / Mobile WebView Domain Rules

## 범위
공통 카드, 반응형, sticky UI, 모달, iOS Safari/WebView 동작.

## 고정 원칙
- 모바일과 데스크톱을 동시에 고려한다.
- 직원 카드 계열의 공통 디자인/열 규칙을 한 화면만 예외적으로 깨지 않는다.
- 전역 touch 이벤트로 클릭 동작을 가로채는 해결은 과거 회귀를 확인한다.
- 입력/모달 수정 시 iOS 키보드, 스크롤, 확대, 닫기 동작의 기존 방어를 확인한다.
- 화면 제목·탭·카드 규격 등 공통 컴포넌트 성격의 변경은 같은 성격 화면을 함께 점검한다.

## 증명
관련 qa_employee_card_*, qa_ios_*, qa_*sticky*, qa_*zoom* 등 기존 자산을 먼저 검색한다.

## 회귀 금지: 본사/지점 헤더
- 지점 선택 콤보는 `#dashboard`에서만 보인다.
- 지점 내부 화면에서는 항상 숨긴다.
- 헤더/라우팅 수정 후 대시보드와 지점 내부 화면을 둘 다 확인한다.
