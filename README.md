# 백억커피 근태 V0.1 (모바일 웹앱)

단일 HTML 파일. 서버 설치 없음. GitHub Pages / Vercel에 그대로 올리면 됩니다.
아이폰 사파리에서 코드 수정 → push → 자동 배포하는 기존 워크플로우와 동일.

## 화면
- `#pos` : 직원 타각 (직원 선택 → PIN 4자리 → 출근/퇴근 자동 판정)
- `#admin` : 오늘 근태 조회 + 직원 등록/비활성화

## 두 가지 모드
- **로컬 모드(기본)** : `CONFIG` 비워두면 이 브라우저 localStorage에만 저장. UI·동선 검증용.
- **클라우드 모드** : Supabase 프로젝트 만든 뒤 `index.html` 상단 `CONFIG.SUPABASE_URL` / `SUPABASE_ANON_KEY` 채우면 자동 전환. 매장 POS·관리자폰이 같은 데이터를 봄.

## Supabase 연결 순서
1. supabase.com에서 새 프로젝트 생성 (근태 전용)
2. SQL Editor에 `schema.sql` 실행
3. Project Settings → API에서 `URL`, `anon key` 복사
4. `index.html`의 `CONFIG`에 붙여넣고 배포
5. 상단 배너가 "클라우드 연결됨"으로 바뀌면 성공

## 검증된 로직 (Node 유닛테스트 통과)
- 자정 넘김(20:00~02:00 = 6h) 정확 계산
- IN/OUT 세션 페어링, 미완결·고아 이벤트 "확인필요" 감지
- 분할근무(4+4) 합산, 8초 중복 타각 방지
- 시각은 항상 Asia/Seoul 기준 저장(PC 시계 무관하게 표시)
- PIN은 PBKDF2-SHA256 해시 저장(평문 저장 안 함)

## 아직 안 만든 것 (다음 스프린트)
월 집계 · 급여/주휴 계산 · 직원 정정요청 · 야간/휴게 · 3.3% 공제.
Sprint 1 목적은 "타각 → 저장 → 조회"가 매장에서 실제로 도는지 검증하는 것까지.

## 주의
- anon 키 공개 상태이므로 실매장 도입 전 Supabase RLS(행 수준 보안) 강화 필수.
- 개인정보(주민번호·계좌)는 이 앱에 저장하지 않음 — 급여계산에 불필요.
